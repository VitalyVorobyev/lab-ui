The four `planar_intrinsics_config`, `rig_extrinsics_config`, `rig_handeye_config` and `dataset_spec` schemas are verbatim copies of `app/src/schemas/*.json` in calibration-rs (schemars 1.x, `cargo xtask emit-schemas`), taken at calibration-rs 0c623a3 (2026-09-30). `detector_config.json` is hand-written in the same schemars style to cover what those four lack: newtype variants (`{"Fixed": 2}`), `x-unit`, a `kind`-tagged enum, a tuple of objects and a nullable number.
